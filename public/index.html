Every task gets a deadline.

To-Do is a task list that asks one extra question: when is it due? Then it shows you what's coming up in the next hour and what you've already missed.

    What it does

    Asks for a deadline

    A task can't be saved without a date and a time, so nothing sits in your list forever.

    In 1 hour Tomorrow Next week

    Flags what's urgent

    Tasks due within the hour are marked as due soon. Tasks past their deadline are marked as missed.

    Due in 42 min Missed 2 h ago

    Ranks by priority

    Mark each task low, medium, or high, then sort the list by priority when you need to choose.

    Low Medium High

    Finds any task

    Search by title, filter by status, and sort by deadline, priority, or name.

    report

    Keeps your list private

    Tasks belong to your account. Nobody else can see them, and your password is stored only as a hash.

    How it runs

    To-Do is also a DevOps project. The app is one small Node.js service; most of the work is in how it gets tested, shipped, and watched. Every change takes the same route to production.

    1. Push

      A commit lands on GitHub.

    2. Test

      GitHub Actions runs ESLint and the Jest test suite.

    3. Build

      A Docker image is built and pushed to Docker Hub.

    4. Scan

      Trivy checks the image for known vulnerabilities.

    5. Deploy

      The image rolls out to Kubernetes on AWS, and a script confirms every replica is healthy.

    App
    Node.js and Express. One container serves this site and the REST API behind it.
    Data
    Amazon DynamoDB, with one table for accounts and one for tasks.
    Sign-in
    Passwords are hashed with bcrypt. Sessions are signed tokens that expire after seven days.
    Infrastructure
    Terraform builds the network and an Amazon EKS cluster. Replicas run behind a load balancer.
    Monitoring
    Prometheus collects metrics and checks alert rules, Grafana charts them, and logs go to CloudWatch.
    Secrets
    The token signing key is kept in AWS Secrets Manager, not in the code or the image.
